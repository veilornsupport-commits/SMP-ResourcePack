# TNT Expansion

Minecraft Forge 1.21.1 mod that adds custom TNT variants.

## Included TNT
- Big TNT — larger explosion than vanilla TNT.
- Napalm TNT — creates fire around the blast.
- Lightning TNT — calls down lightning around the explosion.

## Build

Requirements:
- Java 21
- Minecraft Forge 1.21.1 MDK

Run:

```bash
./gradlew build
```

The built JAR will be in `build/libs/`.
